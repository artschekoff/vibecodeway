Сейчас какая-то путаница со статусами контекстов. При редактировании контекста отображаются только статусы Archived/Active (это нужно переназвать как ArchiveStatus). В листинге статусов отображаются верные статусы (такие как needs attention, not started и т.д.). Я хочу чтобы в контексте можно было переключить этот статус + добавить комментарий. 

Для каждого контекста нужно сохранять StatusLog, в виде двусвязного списка. Каждый элемент - это название статуса + комментарий. Так же я хочу чтобы реализовывалась поддержка следующего user storie:

* Есть задача для выполнения, которая сейчас заблокирована (в теле сказано blocker). Соответственно, эта задача должна при AI анализе принять статус blocked с комментарием почему заблокирована. Этот статус и комментарий должны отображаться в карточке контекста + остаться отображаться в списке контекстов (там при наведении на иконку статуса сейчас уже появляется tooltip). 
* Проходит время - появляется новый комментарий в жира (к примеру), что заблокированный элемент реализован. Я нажимаю на кнопку Refresh -> этот комментарий загружается в контекст. Далее я нажимаю Analyze, нейросеть это видет, видет что задача более не заблокирована - и меняет статус задачи на needs attention с соответствующим комментарием.

Давай расширим настройки для статусов. Я хочу чтобы статус в настройках был ассоциирован с промтом для нейросети, на основе которого она выберет новый статус для задачи. По примеру что я описал выше будет: blocked (этот статус выставляется если ожидается выполнение каких-либо других модулей, исследование, т.д., т.е. прямо сейчас выполнение задачи невозможно). Когда нейросеть обрабатывает новые артефакты контекста, она должна определять новый статус + запоминать причину по которой этот статус был проставлен. В случае с blocked выше: невозможно реализовать т.к. ожидается реализация сервиса А. Этот артефакт должен сохраняться в аттрибутах StatusLog. При новом обновлении AI видет что появился комментарий что сервис А был реализован, сопоставляет прошлый статус-лог что реализация ожидается, сопоставляет эти 2 факта и менят новый статус на needs attention.
